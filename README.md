# Captive Portal – Campus Wi-Fi Access Management

## Overview

Captive Portal is a web application developed as a final project at West Texas A&M University. The application is designed to manage campus Wi-Fi access through user authentication, role-based functionality, and administrative tools.

The project demonstrates full-stack web development, relational database integration, and the implementation of business rules within a web application.

## Technologies Used

- **Backend:** ASP.NET Core, C#
- **Frontend:** Razor Pages
- **Database:** Microsoft SQL Server
- **ORM:** Entity Framework
- **Architecture:** Database-backed web application

## Key Features

### User Authentication and Verification
- User verification and authentication functionality
- Role-based access to application features
- Session management for authenticated users

### Administrative Dashboard
- Administrative interface for managing portal functionality
- Role-specific functionality for authorized users

### Advertisement Management
- Dynamic advertisement rotation
- Integration of advertisement functionality into the captive portal experience

### Database Integration
- SQL Server database for persistent application data
- Entity Framework for database operations
- Structured storage and retrieval of application information

## Project Purpose

The application was developed to explore how a centralized web-based system could manage access to campus network services while providing administrative oversight and configurable content.

The project incorporates several important concepts:

- Full-stack application development
- Relational database design
- Authentication and authorization
- Session management
- Role-based business logic
- Administrative workflows
